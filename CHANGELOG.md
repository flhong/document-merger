# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-09-01

### Added
- Initial release of Document Merger
- **PDFMerger**: Merge multiple PDF files with automatic bookmark extraction and TOC generation
- **WordMerger**: Merge Word documents while preserving formatting with auto-refresh TOC
- **HybridMerger**: Merge mixed PDF and Word documents with automatic format conversion
- **TOCManager**: Comprehensive table of contents management with multiple styles (formal, simple, hierarchical)
- **BookmarkManager**: PDF bookmark/outline hierarchy management
- **Configuration System**: YAML-based configuration for customizing merge behavior
- **CLI Interface**: Command-line interface for batch operations
- **Interactive Mode**: User-friendly interactive menu for manual merging
- **Comprehensive Test Suite**: Unit tests for all major components
- **Test Data Generator**: Automatic generation of sample PDF and Word documents
- **Examples**: Full working examples for PDF, Word, and hybrid merging

### Features
- Automatic TOC generation from document structure
- Automatic page number updates (auto-refresh)
- Multi-level bookmark/outline support
- Multiple TOC styling options
- Batch processing support
- Method chaining for fluent API
- Comprehensive error handling
- Detailed logging and progress reporting

### Documentation
- Complete README with quick start guide
- API documentation with docstrings
- Multiple working examples
- Configuration guide
